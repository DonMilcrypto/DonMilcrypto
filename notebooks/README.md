# 📓 Notebooks Directory

This folder contains the main AI image generation notebooks for Google Colab.

## 📌 Available Notebooks

### 🌟 **fooocus_livedraw.ipynb** (RECOMMENDED)
**Best for:** Beginners, quick experimentation, interactive use

- Lightweight and fast
- Easy-to-use web interface
- Works great on free T4 GPU
- ~30 seconds per image

**[Open in Colab →](https://colab.research.google.com/github/DonMilcrypto/DonMilcrypto/blob/main/notebooks/fooocus_livedraw.ipynb)**

---

### ⚡ **flux.ipynb** (ADVANCED)
**Best for:** High-quality images, cutting-edge models

- State-of-the-art Flux model
- Highest quality outputs
- Requires more VRAM (8GB+)
- Recommended: A100 GPU

**[Open in Colab →](https://colab.research.google.com/github/DonMilcrypto/DonMilcrypto/blob/main/notebooks/flux.ipynb)**

---

## 🚀 Quick Start

1. Click one of the links above
2. Runtime → Change runtime type → **GPU**
3. Run all cells (Ctrl+F9)
4. Wait for Gradio URL
5. Click the URL to generate images
