# Contributing to DonMilcrypto/AI-Generation-Tools\n\nThanks for your interest in contributing! This guide will help you improve the notebooks and documentation.\n\n## 📋 Code of Conduct\n\n- Be respectful and constructive\n- Help others learn\n- Report issues, don't just complain\n- Test your changes before submitting\n\n---\n\n## 🐛 Reporting Issues\n\n### Before Creating an Issue\n- Check if it's already been reported\n- Try restarting your Colab runtime\n- Verify you're using a GPU (Runtime → Change runtime type)\n- Check the [README.md troubleshooting section](README.md#-troubleshooting)\n\n### When Creating an Issue\nInclude:\n1. **Which notebook?** (Fooocus-Lite, Flux, or Stable Diffusion Videos)\n2. **What happened?** (Exact error message)\n3. **What did you expect?** (Expected behavior)\n4. **GPU used:** (T4, A100, etc.)\n5. **Steps to reproduce:** (What did you click/run?)\n\n---\n\n## 🎯 Feature Requests\n\nHave an idea? Great! Please:\n1. Check if it's already suggested\n2. Explain the use case\n3. Describe the expected behavior\n4. Suggest how you'd implement it (optional)\n\n---\n\n## 💻 Submitting Changes\n\n### Notebook Improvements\n1. **Test locally or in Colab first**\n   - Run on free T4 GPU if possible\n   - Test both first-run and cached scenarios\n\n2. **Document your changes**\n   - Add markdown cells explaining new steps\n   - Include error handling\n   - Add comments for complex code\n\n3. **Follow the format**\n   - Use clear section headers (## Step X: ...)\n   - Include status emojis (✅, ⚠️, ❌)\n   - Keep cells focused and logical\n\n4. **Test error cases**\n   - What if GPU is missing?\n   - What if installation fails?\n   - Add try/except blocks appropriately\n\n### Documentation Improvements\n1. **Check for clarity**\n   - Is it understandable to beginners?\n   - Are there typos or broken links?\n   - Could images/diagrams help?\n\n2. **Update the README if needed**\n   - Keep \"Available Tools\" section current\n   - Update troubleshooting for new issues\n   - Add examples if helpful\n\n3. **Keep it organized**\n   - Use markdown headers properly\n   - Keep tables up-to-date\n   - Maintain consistent formatting\n\n---\n\n## 🔍 Review Process\n\n1. **I'll review your submission**\n   - Check for quality and accuracy\n   - Test in Colab if it's a notebook\n   - Verify documentation changes\n\n2. **We may ask for changes**\n   - Be responsive to feedback\n   - Ask questions if unclear\n   - Make requested updates\n\n3. **Once approved, it merges!**\n   - Thanks for contributing! 🎉\n\n---\n\n## 📚 Development Setup\n\nIf you want to test notebooks locally:\n\n```bash\n# Clone the repo\ngit clone https://github.com/DonMilcrypto/DonMilcrypto.git\ncd DonMilcrypto\n\n# Install Jupyter locally (optional, for editing)\npip install jupyter notebook\n\n# Edit notebooks, then commit changes\ngit add .\ngit commit -m \"Description of changes\"\ngit push origin your-branch-name\n```\n\nThen open a Pull Request on GitHub.\n\n---\n\n## ✅ Checklist Before Submitting\n\n- [ ] I've tested my changes in Colab\n- [ ] Error handling is implemented (try/except where needed)\n- [ ] Documentation/comments are clear\n- [ ] No hardcoded paths or personal info\n- [ ] Links are up-to-date\n- [ ] Formatting is consistent with existing code\n- [ ] I've updated README.md if needed\n\n---\n\n## 🙏 Thanks!\n\nEvery contribution makes this project better. Thank you for helping! 🚀\n\n---\n\n**Questions?** Open an issue or check the README.md.\n"
