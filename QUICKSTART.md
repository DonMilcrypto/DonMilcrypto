# ⚡ Quick Start (5 Minutes)

## For the Impatient

### 1️⃣ Open Notebook
Click here → **[Open Fooocus-Lite in Colab](https://colab.research.google.com/github/DonMilcrypto/DonMilcrypto/blob/main/notebooks/fooocus_livedraw.ipynb)**

### 2️⃣ Check GPU
- Top right: `Runtime` → `Change runtime type`
- Select **GPU (T4 or better)**
- Click **Save**

### 3️⃣ Run All Cells
- Keyboard: **Ctrl+F9** (or Cmd+F9 on Mac)
- Or: Menu → `Runtime` → `Run all`
- Wait 5-10 minutes (first time) or 2-3 minutes (cached)

### 4️⃣ Open Interface
- Look for a link like: `https://abc123.gradio.app`
- **Click it** to open the web interface in full screen

### 5️⃣ Generate!
- Type a prompt: *"a cat riding a surfboard"*
- Click **Generate**
- Wait ~30 seconds
- See your AI art! 🎨

## 🆘 Something Went Wrong?

| Error | Fix |
|-------|-----|
| **"No GPU available"** | Runtime → Change runtime type → Select GPU |
| **"CUDA out of memory"** | Runtime → Restart runtime. Then re-run all cells |
| **Module not found** | Re-run first 3 cells (installation) |
| **Link doesn't work** | Gradio links expire. Re-run the launch cell |

- ✅ **First run is slow** — be patient, models are downloading
- ✅ **Try simple prompts first** — *"a cat"* before *"a photorealistic cat riding a laser-powered unicorn through neon Tokyo"*
